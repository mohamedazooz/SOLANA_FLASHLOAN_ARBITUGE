## Archival Rules

1. **Immutability**: Archived documents are preserved for forensic history and should not be modified to reflect current findings.
2. **Explicit Banners**: Every archived document carries an archive notice alerting future agents and maintainers that the document is historical.
3. **No Stale Authority**: When conflicts exist between an archived document and a document in `docs/active/`, the active document always takes precedence.
