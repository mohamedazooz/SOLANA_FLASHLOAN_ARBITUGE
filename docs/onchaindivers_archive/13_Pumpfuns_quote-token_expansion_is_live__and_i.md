    toDateTime('2026-09-09 20:30:00', 'UTC') AS start_ts,
    toDateTime('2026-09-09 22:30:00', 'UTC') AS end_ts
SELECT
    replaceAll(toString(quote_coin), char(0), '') AS quote_coin,
    uniqExact(replaceAll(toString(mint), char(0), '')) AS launches,
    uniqExact(replaceAll(toString(creator), char(0), '')) AS creators,
    toTimeZone(min(block_time), 'UTC') AS first_launch_utc,
    toTimeZone(max(block_time), 'UTC') AS last_launch_utc
FROM default.pumpfun_token_creation
WHERE block_time &gt;= start_ts
  AND block_time &lt; end_ts
GROUP BY quote_coin
ORDER BY launches DESC;</code></pre></div><p>And the swap-side check:</p><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;sql&quot;,&quot;nodeId&quot;:&quot;8983618d-c074-430a-aedf-a03a6aa427f9&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-sql">WITH
    toDateTime('2026-09-09 20:30:00', 'UTC') AS start_ts,
    toDateTime('2026-09-09 22:30:00', 'UTC') AS end_ts
SELECT
    quote_coin,
    countIf(failed = 0) AS successful_swap_rows,
    uniqExactIf(signature, failed = 0) AS successful_transactions,
    uniqExactIf(base_coin, failed = 0) AS traded_launches,
    uniqExactIf(signing_wallet, failed = 0) AS signing_wallets
FROM default.pumpfun_v2_swaps
WHERE block_date_utc = toDate('2026-09-09')
  AND block_time &gt;= start_ts
  AND block_time &lt; end_ts
GROUP BY quote_coin
ORDER BY successful_transactions DESC;</code></pre></div><p>Do not sum <code>quote_coin_amount</code> across different mints. It is a raw integer in each quote asset’s own decimals. Normalize per mint first, then apply a contemporaneous price if a cross-asset dollar view is required.</p><h2><strong>What this enables</strong></h2><p>The new field makes several analyses possible without reconstructing quote identity from token transfers:</p><ul><li><p>compare launch activity across quote regimes;</p></li><li><p>build quote-specific prices and turnover;</p></li><li><p>separate creator fees by settlement asset;</p></li><li><p>measure whether sniper behavior changes between SOL, equities, commodities and crypto quotes;</p></li><li><p>follow a launch into migration without losing the original quote denomination.</p></li></ul><p>The registry tells us what Pump.fun configured. The indexer shows what people actually launched and traded.</p><p>OnChainDivers subscribers can query both sides directly: <code>pumpfun_token_creation.quote_coin</code> for the launch and <code>pumpfun_v2_swaps.quote_coin</code> for the executed market.</p><h2><strong>Sources and reproducibility</strong></h2><ul><li><p><a href="https://solscan.io/account/6z6GDdfb2AjR9ZhJmAUQ5cipJCVxQvLJhB2H8mCwTFBP#accountData">Pump.fun QuoteControl account<span>(opens in new tab)</span></a></p></li><li><p><a href="https://solscan.io/tx/3ULbKDUPuEVADdBEnmmY8owHD1SzjrsDnULe2Qk6nmfLmeDBq8gYrCw9n68TTpRRdTkGBpoFGAoYTPQzsCfJgqH3">QuoteControl initialization transaction<span>(opens in new tab)</span></a></p></li><li><p><a href="https://solscan.io/tx/oYQAamkxAdhEaAAS5HWSac4HupMsNEEJmo8hXxPsY19YzAqT1UpQw4LGhttdDYxugEDVNStXjt17E6nfsccsjb9">Batch containing the GOOGLx QuoteControl addition<span>(opens in new tab)</span></a></p></li><li><p><a href="https://github.com/pump-fun/pump-public-docs/blob/main/idl/pump.json">Pump.fun public program IDL<span>(opens in new tab)</span></a></p></li></ul><p>The complete executed queries are included alongside this article as <code>fresh_quote_summary.sql</code>, <code>fresh_swap_quote_summary.sql</code> and <code>fresh_exotic_launches.sql</code>.</p><div><hr></div><p><em>OnChainDivers provides indexed Solana launch, swap and migration data for researchers building lifecycle-aware market models.
