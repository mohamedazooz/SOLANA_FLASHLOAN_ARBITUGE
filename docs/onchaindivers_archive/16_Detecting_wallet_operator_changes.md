If control of that wallet changes, the address stays the same while the transaction builder often does not. The indexer makes those construction details queryable, so monitoring can look beyond PnL and token selection.</p><p>This is not a hypothetical risk - it's a known pattern on copytrading platforms like <strong>Axiom</strong>. A trader builds a wallet, the wallet gets noticed and starts getting copied, and then the trader sells that same wallet to a bad-faith token creator, who uses the copied reputation to push their own tokens onto the copytraders still following it. Because these platforms surface wallets primarily as addresses with a PnL history, a sold wallet is invisible to the signal they optimize for.
