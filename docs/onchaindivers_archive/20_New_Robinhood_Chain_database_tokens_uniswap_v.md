For example, daily trade rows are:</p><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;sql&quot;,&quot;nodeId&quot;:&quot;cd451bf7-7963-4577-a446-935652ab42da&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-sql">SELECT
    toDate(block_timestamp) AS day,
    count() AS trades
FROM robinhood.uniswap_v4_trades
WHERE block_timestamp &gt;= toDateTime('2026-05-22 00:00:00', 'UTC')
  AND block_timestamp &lt;  toDateTime('2026-08-05 00:00:00', 'UTC')
GROUP BY day
ORDER BY day;</code></pre></div><p>For cumulative unique addresses, first reduce every address to its first observed trading day, count new addresses by day, and cumulatively sum those daily cohorts. Pools use the same pattern with <code>pool_id</code>. The complete SQL and Python plotting script are included with this release.</p><h2><strong>What this unlocks</strong></h2><p>The three tables can be joined to build:</p><ul><li><p>token creation-to-first-pool and first-trade timelines;</p></li><li><p>pool discovery and hook/fee adoption monitoring;</p></li><li><p>trading participation and repeat-address cohorts;</p></li><li><p>token, pool, and transaction-level quality checks;</p></li><li><p>recurring Robinhood Chain activity pulses.</p></li></ul><p>This announcement only establishes the data surface.
