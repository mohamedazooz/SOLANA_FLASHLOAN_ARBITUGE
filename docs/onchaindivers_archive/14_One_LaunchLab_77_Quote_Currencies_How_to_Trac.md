Find the StonkFun migrated cohort</strong></h3><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;sql&quot;,&quot;nodeId&quot;:&quot;729b85ed-dda3-4baa-972f-fafdf366eac9&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-sql">SELECT
    quote_mint,
    arrayStringConcat(arraySort(groupUniqArray(global_config)), ';') AS config_ids,
    uniqExact(base_mint) AS migrated_tokens,
    uniqExact(signature) AS migration_txs,
    toTimeZone(min(block_time), 'UTC') AS first_migration_utc,
    toTimeZone(max(block_time), 'UTC') AS last_migration_utc
FROM default.raydium_launchpad_cpmm_migrations
PREWHERE block_date_utc BETWEEN toDate('2026-08-20') AND toDate('2026-09-08')
WHERE block_time &gt;= toDateTime('2026-08-20 00:00:00', 'UTC')
  AND block_time &lt;  toDateTime('2026-09-08 15:30:00', 'UTC')
  AND platform_config = '6BwHHDg3u1854jC8PDLXvR4spTcLNaoBxLJNGC4nTESt'
  AND failed = 0
GROUP BY quote_mint
ORDER BY migrated_tokens DESC, quote_mint;</code></pre></div><h3><strong>2. Recover pre-migration curve trades</strong></h3><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;sql&quot;,&quot;nodeId&quot;:&quot;fbd479be-096c-4127-b65d-3e273bbab066&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-sql">WITH stonkfun_pools AS (
    SELECT DISTINCT pool_state
    FROM default.raydium_launchpad_cpmm_migrations
    WHERE block_time &gt;= toDateTime('2026-08-20 00:00:00', 'UTC')
      AND block_time &lt;  toDateTime('2026-09-08 15:30:00', 'UTC')
      AND platform_config = '6BwHHDg3u1854jC8PDLXvR4spTcLNaoBxLJNGC4nTESt'
      AND failed = 0
)
SELECT
    s.slot,
    s.tx_idx,
    s.signature,
    s.pool_state,
    s.base_token,
    s.quote_token,
    s.direction,
    s.base_token_amount,
    s.quote_token_amount,
    s.pool_base_token_reserves_after,
    s.pool_quote_token_reserves_after,
    s.parent_program
FROM default.raydium_launchpad_swaps AS s
INNER JOIN stonkfun_pools AS p ON s.pool_state = p.pool_state
WHERE s.block_time &gt;= toDateTime('2026-08-20 00:00:00', 'UTC')
  AND s.block_time &lt;  toDateTime('2026-09-08 15:30:00', 'UTC')
ORDER BY s.slot, s.tx_idx;</code></pre></div><p>This query is intentionally restricted to pools that eventually migrated. It does not discover active, not-yet-migrated StonkFun curves.</p><h3><strong>3. Map migration into the destination pool</strong></h3><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;sql&quot;,&quot;nodeId&quot;:&quot;9038bc44-e4ff-453a-bf6c-56c9df74a112&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-sql">SELECT
    slot,
    tx_idx,
    signature AS migration_signature,
    base_mint,
    quote_mint,
    global_config,
    platform_config,
    pool_state,
    cpswap_pool,
    payer
FROM default.raydium_launchpad_cpmm_migrations
WHERE block_time &gt;= toDateTime('2026-08-20 00:00:00', 'UTC')
  AND block_time &lt;  toDateTime('2026-09-08 15:30:00', 'UTC')
  AND platform_config = '6BwHHDg3u1854jC8PDLXvR4spTcLNaoBxLJNGC4nTESt'
  AND failed = 0
ORDER BY slot, tx_idx;</code></pre></div><h3><strong>4. Continue into post-migration CPMM trading</strong></h3><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;sql&quot;,&quot;nodeId&quot;:&quot;094ad361-9e30-490a-b7fc-22578e6df582&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-sql">WITH migrated AS (
    SELECT DISTINCT cpswap_pool, base_mint, quote_mint
    FROM default.raydium_launchpad_cpmm_migrations
    WHERE block_time &gt;= toDateTime('2026-08-20 00:00:00', 'UTC')
      AND block_time &lt;  toDateTime('2026-09-08 15:30:00', 'UTC')
      AND platform_config = '6BwHHDg3u1854jC8PDLXvR4spTcLNaoBxLJNGC4nTESt'
      AND failed = 0
)
SELECT
    s.slot,
    s.tx_idx,
    s.swap_idx,
    s.signature,
    s.pool_id,
    m.base_mint,
    m.quote_mint,
    s.direction,
    s.base_coin_amount,
    s.quote_coin_amount,
    s.parent_program
FROM default.raydium_cpmm_swaps AS s
INNER JOIN migrated AS m ON s.pool_id = m.cpswap_pool
WHERE s.block_time &gt;= toDateTime('2026-08-20 00:00:00', 'UTC')
  AND s.block_time &lt;  toDateTime('2026-09-08 15:30:00', 'UTC')
ORDER BY s.slot, s.tx_idx, s.swap_idx;</code></pre></div><h2><strong>The remaining coverage gap</strong></h2><p>The current indexer already reconstructs the full lifecycle for pools that migrated. But <code>platform_config</code> and <code>global_config</code> are stored in the CPMM migration table, not in the current creation and curve-swap tables.</p><p>That creates one blind spot: a platform-complete query cannot enumerate StonkFun curves that are still active and have never migrated. There are two valid ways to close it:</p><ol><li><p>decode each LaunchLab <code>pool_state</code> account, whose layout contains both <code>platformId</code> and <code>configId</code>; or</p></li><li><p>add <code>platform_config</code> and <code>global_config</code> directly to <code>raydium_launchpad_token_creation</code> and <code>raydium_launchpad_swaps</code> during indexing.</p></li></ol><p>The second option is better for analysts. It turns a future-dependent backfill into a causal launch-time field and makes queries cheaper.</p><h2><strong>What this changes</strong></h2><p>The right statement is no longer “we support a handful of Raydium LaunchLab tokens quoted in xStocks.”</p><p>The stronger and more precise statement is:</p><blockquote><p><em>OnChainDivers indexes the Raydium LaunchLab and CPMM lifecycle used by StonkFun — creation, curve trading, migration mapping and post-migration swaps — for the platform-tagged migrated cohort across 77 quote currencies.</em></p></blockquote><p>The qualifier still matters. Until platform IDs are stored at creation time, complete coverage of ungraduated StonkFun curves requires RPC account decoding. But the protocol path itself is no longer missing. The data is already there; the platform ID is what makes it coherent.</p><div><hr></div><p><em>OnChainDivers provides indexed Solana launch, swap and migration data for researchers building lifecycle-aware market models.
