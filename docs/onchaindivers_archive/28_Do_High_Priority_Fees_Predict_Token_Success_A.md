# Do High Priority Fees Predict Token Success? Analyzing 138K Pumpfun Launches

- **Date**: 2026-05-01

- **Description**: Does paying higher landing fees actually correlate with token success?

---

<p>When a new token launches on Pumpfun, the first few slots are a battleground. Bots compete to be first, snipers pay premium priority fees, and landing fees, and the early price action often determines whether a token moons or dies.</p><p><strong>But does paying higher landing fees actually correlate with token success?</strong></p><div class="subscription-widget-wrap-editor" data-attrs="{&quot;url&quot;:&quot;https://onchaindivers.substack.com/subscribe?&quot;,&quot;text&quot;:&quot;Subscribe&quot;,&quot;language&quot;:&quot;en&quot;}" data-component-name="SubscribeWidgetToDOM"><div class="subscription-widget show-subscribe"><div class="preamble"><p class="cta-caption">Thanks for reading! The results reveal a surprisingly strong relationship between early fee competition and price performance.</p><h2><strong>Key Findings</strong></h2><ul><li><p><strong>Spearman correlation: 0.447</strong> - Strong positive relationship between total landing fees and max price</p></li><li><p><strong>Log-log correlation: 0.308</strong> - The relationship follows a power law distribution</p></li><li><p>Median langing fee per token: <strong>0.014 SOL</strong> in first 10 slots</p></li><li><p>Some tokens saw up to <strong>26.5 SOL</strong> in total landing fees early on</p></li></ul><h2><strong>The Data</strong></h2><p>We pulled two datasets from our ClickHouse database:</p><ol><li><p><strong>Token Launches</strong>: All tokens created on Pumpfun in the last 7 days (179,773 total)</p></li><li><p><strong>Early Swaps</strong>: All swaps occurring in the first 10 slots after each token’s creation slot</p></li></ol><h3><strong>Data Collection Query</strong></h3><p>Here’s how we fetched the early swap data:</p><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;sql&quot;,&quot;nodeId&quot;:&quot;b4284e67-370e-4b5b-ab3b-f8d9f2fddde2&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-sql">WITH token_launches AS (
    SELECT
        mint,
        slot as creation_slot
    FROM pumpfun_token_creation
    WHERE block_time &gt;= now() - INTERVAL 7 DAY
)
SELECT
    s.base_coin as mint,
    s.slot,
    s.signing_wallet,
    s.direction,
    s.base_coin_amount,
    s.quote_coin_amount,
    s.top_level_transfers_json,
    t.creation_slot,
    s.slot - t.creation_slot as slots_after_launch,
    s.fee
FROM pumpfun_all_swaps s
INNER JOIN token_launches t ON s.base_coin = t.mint
WHERE s.slot &gt;= t.creation_slot
    AND s.slot &lt; t.creation_slot + 10
ORDER BY s.base_coin, s.slot</code></pre></div><p>This gave us <strong>1,203,014 swaps</strong> across <strong>167,471 tokens</strong> that had trading activity in their first 10 slots.</p><h2><strong>Extracting Landing Fees</strong></h2><p>On Solana, landing fees appear primarily as transfers in the <code>top_level_transfers_json</code> field. We extracted total fees paid per token:</p><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;python&quot;,&quot;nodeId&quot;:&quot;bacd525f-75a4-4ea1-a3ef-43231838435f&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-python">import json

def extract_total_lamports(transfers_json: str) -&gt; int:
    """Extract total lamports from top_level_transfers_json."""
    if not transfers_json or transfers_json == '[]':
        return 0
    try:
        transfers = json.loads(transfers_json)
        total = 0
        for t in transfers:
            lamports = t.get('lamports', 0)
            # Handle string or int values
            if isinstance(lamports, str):
                total += int(lamports)
            else:
                total += lamports
        return total
    except (json.JSONDecodeError, TypeError, ValueError):
        return 0</code></pre></div><h3><strong>Calculating Max Price</strong></h3><p>For each swap, we calculated price as the ratio of SOL to tokens:</p><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;python&quot;,&quot;nodeId&quot;:&quot;3b7f6490-f20a-432f-adb3-688c94650336&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-python">def calculate_price(row) -&gt; float:
    """Calculate price as quote/base (SOL per token)."""
    if row['base_coin_amount'] == 0:
        return 0
    return row['quote_coin_amount'] / row['base_coin_amount']</code></pre></div><p>We then took the <strong>maximum price</strong> observed across all early swaps for each token.</p><h2><strong>The Possible explanations:</p><ol><li><p><strong>Demand drives both</strong> - Popular tokens attract both high fees AND high prices</p></li><li><p><strong>Bot sophistication</strong> - Better bots pay more fees AND pick better tokens</p></li><li><p><strong>Self-fulfilling prophecy</strong> - Early buying pressure from fee-payers drives price up</p></li><li><p><strong>Survivor bias</strong> - We only see tokens that had trading activity</p></li></ol><h2><strong>The Code</strong></h2><p>Full analysis pipeline:</p><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;python&quot;,&quot;nodeId&quot;:&quot;eae82842-0a76-4d8e-904d-ceb7f5acb22d&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-python"># Aggregate metrics per token
