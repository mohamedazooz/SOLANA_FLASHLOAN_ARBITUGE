reserves before the swap;</p></li><li><p><code>Q</code> be the raw quote-token reserves before the swap;</p></li><li><p><code>Vq</code> be <code>virtual_quote_reserves</code>.</p></li></ul><p>PumpSwap’s official documentation defines:</p><pre><code><code>Q_effective = Q + Vq</code></code></pre><p>Only <code>Q</code> is adjusted. <code>B</code> remains the raw base reserve.</p><h3>Buy: quote coin in, base coin out</h3><p>For an exact-quote buy, let <code>T</code> be the user’s total quote input. PumpSwap first separates the LP, protocol and active creator route. The active creator route can be a normal creator fee or, as in the example below, cashback.</p><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;plaintext&quot;,&quot;nodeId&quot;:&quot;82f66501-401e-416f-88d0-62ae907702fd&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-plaintext">E = T - lp_fee - protocol_fee - creator_or_cashback_fee
x = E - 1                 # integer adjustment used by the SDK

base_output = floor(
    B * x
    / (Q_effective + x)
)</code></pre></div><p>The swap event state is then:</p><pre><code><code>B_after = B - base_output
Q_after = Q + T</code></code></pre><p>Before the following swap, protocol and creator/cashback amounts leave the pool while the LP fee remains in it:</p><pre><code><code>Q_next_before = Q_after - protocol_fee - creator_or_cashback_fee</code></code></pre><p>In the five rows below, <code>buy_back_fees</code> is a routing split of the protocol fee, not another fee to subtract from the pricing input.</p><h3>Sell: base coin in, quote coin out</h3><p>For a sell, let <code>A</code> be the base-token input:</p><pre><code><code>gross_quote_output = floor(
    A * Q_effective
    / (B + A)
)</code></code></pre><p>Fees are calculated on that gross quote output. The user's net quote receipt is:</p><pre><code><code>user_quote_output =
    gross_quote_output
    - lp_fee
    - protocol_fee
    - creator_or_cashback_fee</code></code></pre><p>The event state is:</p><pre><code><code>B_after = B + A
