database</strong></h2><p>We built <a href="https://astrolabe.cartographer.club">Astrolabe</a> so that anyone can work with the same on-chain data we use every day, for free. It’s a free workbench built on the <a href="https://onchaindivers.com">Onchain Divers indexers</a>. The indexer is a full ClickHouse database with the complete history. Astrolabe is a Dune-style layer on top of it. You write SQL or ask the built-in AI assistant to write it, chart the results, build dashboards, share or embed them, and fork public work. The MCP server is free and needs no key and no sign-up:</p><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;plaintext&quot;,&quot;nodeId&quot;:&quot;4e0361df-83a5-434e-97d1-d7264811d481&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-plaintext">https://astrolabe.cartographer.club/mcp</code></pre></div><div class="highlighted_code_block" data-attrs="{&quot;language&quot;:&quot;plaintext&quot;,&quot;nodeId&quot;:&quot;a0c3a53a-85a6-4c30-bc9b-0f7c17b1ba42&quot;}" data-component-name="HighlightedCodeBlockToDOM"><pre class="shiki"><code class="language-plaintext">Claude Code setup is one line:
claude mcp add --transport http astrolabe https://astrolabe.cartographer.club/mcp</code></pre></div><p>Setup for the Claude app, Cursor, Codex, ChatGPT and any other MCP client is at <a href="https://astrolabe.cartographer.club/agents">astrolabe.cartographer.club/agents</a>.</p><p>Paste this as your first prompt:</p><blockquote><p>Show me pump.fun token launches per day over the last 7 days, and give me a link I can share.</p></blockquote><p>Here is what happens next:</p><ol><li><p><strong>The agent finds the tables</strong> and reads the description of every column, including units.</p></li><li><p><strong>It reads our rules.</strong> A dedicated <code>AGENTS</code> database holds our notes on units, freshness, partition filters and known quirks, plus verified example queries. This is why the agent writes correct SQL instead of guessing.</p></li><li><p><strong>It writes and runs the query.</strong></p></li><li><p><strong>It saves the result as a public page</strong> with a chart and sends you the link.</p></li></ol><p>Ask for a single number and you get a number. Ask for a series, a breakdown or a comparison and you get a chart with a link. Ask for a dashboard and the agent builds one. Paste a link to someone else’s dashboard and ask for changes: the agent forks it and edits the copy, never the original.</p><p>A more involved example is <a href="https://astrolabe.cartographer.club/queries/573">Pump.fun / PumpSwap: best wallets for copy-trading, last 10 days</a>, built entirely by an agent. It reconstructs realized PnL per token for closed positions, then filters for organic win rates, minimum holding time and profit factor. It shows that an agent can do non-trivial research on its own. The result is still a starting point, not a signal.</p><p><em>For developers:</em> the data tools are the official <code>mcp-clickhouse</code> ones (<code>list_databases</code>, <code>list_tables</code>, <code>run_query</code>). Astrolabe adds <code>save_query</code>, <code>create_dashboard</code>, <code>fork_dashboard</code>, <code>search</code> and a few more. Everything agents save is public, in English, under the <code>agents</code> account.</p><h2><strong>A free account adds your own data and alerts</strong></h2><p>Registration is free, and it turns Astrolabe from a viewer into a working tool:</p><ul><li><p><strong>Your own data:</strong> upload a CSV, such as your wallet list, labels or watchlist, as a table and join it with the indexer data.</p></li><li><p><strong>Alerts:</strong> any saved query can run on a schedule and send an e-mail or a webhook to Slack, Discord or Telegram when its result meets a condition.</p></li><li><p><strong>Private work:</strong> private queries and dashboards, saved across devices, plus stars and a public profile page.</p></li></ul><p>Put those together: upload a list of wallets you follow, join it with pump.fun activity, and get a Telegram ping when one of them buys a fresh token.</p><h2><strong>Free, registered and live</strong></h2><p><strong>No account (free)</strong> - SQL editor, charts, dashboards, parameters, forks, embeds, sharing, AI assistant - MCP server for agents, with no key - About 90 days of history, loaded daily at 11:00 UTC for the previous UTC day - Everything you save is public</p><p><strong>Free account</strong> - Everything above - Private work, CSV uploads, alerts, stars and a profile page</p><p><strong>Live access (200 USDC per indexer per 30 days)</strong> - The indexers themselves, seconds behind the chain - Full history: Solana since 2024, Polymarket since 2022, Hyperliquid since July 2025 - Team research tables: wallet clusters, labels and derived views - One switch moves your existing queries and dashboards to live data, with nothing to rewrite - A direct read-only ClickHouse login with no API layer and no request limits, for Python, DBeaver, Grafana, Jupyter or your own code.
