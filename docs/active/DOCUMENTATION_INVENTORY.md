# Master Documentation Inventory

This inventory catalogs every documentation, audit, report, and reference file across the repository as of the documentation reset baseline (commit `d090123`).

**Total Documents Preserved**: 315+ core documents (plus reference archive snapshots).  
**Zero Deletions Policy**: No historical documents, logs, or evidence have been deleted.

---

## 1. Classification Methodology

Every document in the repository is classified into one of four distinct categories:

1. **Active**: The current, authoritative source of truth. Located in `docs/active/`, `docs/agents/`, or repository root (`README.md`, `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `SECURITY.md`, `Cargo.toml`).
2. **Historical**: Valid past research, audits, reports, or test evidence that reflected previous project milestones or legacy implementations. Preserved in `docs/archive/` with explicit archive notices.
3. **Duplicate / Snapshot**: Exact or near-exact copies of past reports generated by automated test runs or legacy snapshots. Preserved in `docs/reference_archive/` or specific archive subfolders.
4. **Unclear / Deprecated**: Fragmented notes, unverified claims, or incomplete drafts. Preserved in `docs/archive/legacy/` for review rather than deleted.
