WINDOWS INSTALL

1) Back up any existing .roomodes in the target repository.
2) Extract this ZIP directly into the repository root.
3) If .roomodes already existed, merge the customModes entries; do not blindly overwrite it.
4) In VS Code press Ctrl+Shift+P and run: Developer: Reload Window
5) Open Roo Code > Modes. Confirm the eight custom modes are visible.
6) Open Roo Code Settings > Providers and create OR-HYBRID and OR-FREE profiles using the OpenRouter provider and your API key.
7) Select each mode and choose the model ID shown in README-AR.md. Roo remembers the last model per mode.

Do not store API keys, private keys, passwords, .env files, or production credentials in this package or Git.
